元アドオンのテクスチャ・文言・コードは使用せず、挙動を参考にして独自に実装しています。

## Phase 2 の機能

- **鉱石ブレーカー**：ツルハシで鉱石を壊すと、同種の鉱石を26近傍のBFSで連鎖破壊します（探索半径 1〜8、既定5）。
- **ストーンブレーカー**：ツルハシで石系を壊すと、向いている方向の範囲（幅・高さ・奥行き各1〜3、既定3×3×3）をまとめて破壊します。黒曜石は設定 `obsidianInStoneBreaker` が ON かつダイヤモンド以上のツルハシのみ対象です。
- **サンドブレーカー**：シャベルで砂系・土系を壊すと、ストーンブレーカーと同じ範囲を破壊します。砂利は既定ON、ソウルサンド・ソウルソイルは既定OFFです。
- **ツリーブレーカー**：斧で原木を壊すと、接続する同種原木をBFSで伐採します。上方向を優先し、既定では起点から半径16以内に限定します。耐久は既定で「伐採1回につき1」（固定）です。
- **リーブスブレーカー**（既定OFF）：伐採後、半径6内の葉をシルクタッチ相当で破壊します。
- **木の再植え付け**（既定ON）：伐採後、最も低い原木の位置に、所持している苗木を1本植えます。土系ブロック以外には植えません。

### 共通仕様
- 破壊は `ServerTickEvents` で tick ごとに分散実行します。
- 速度制限 `breakerSpeedLimit`：1〜20 は1tickあたりの破壊数、0 は MSPT に応じた自動調整（開始32、MSPT>45 で半減、<10 で+8、上限256）。
- 1回の連鎖の総上限 `maxChainBlocks`（既定512、1〜4096）。
- 連鎖中にログアウトしたら、そのプレイヤーの連鎖ジョブを破棄します。
- 再帰防止は `BreakGuard`（ThreadLocal）で行います。
- 優先順位は `BreakDispatcher` で管理し、最初に発動したブレーカーで打ち切ります（1:スポナー、2:ツリー、3:作物、4:鉱石、5:石、6:砂）。スポナーと作物は今後のPhaseで追加します。
- シフト判定は既定で「シフト中は発動しない」です。各機能の `*InvertSneak` を true にすると「シフト中のみ発動」になります。

## 設定ファイル（config/essentials_like.json）

設定は `global`（管理者用）と `player`（個別用）に分かれています。`global` は OP / ホストのみ変更できる想定です。現時点では `player` は全員共通のデフォルトとして読み込まれます。個別化は Phase 8 で行います。

壊れた設定ファイルは `.bak` に退避し、デフォルトで再生成して警告ログを出します。範囲外の数値は読み込み時に丸めます。

## 仮定事項（Phase 2）

1. **ペールオーク**：Minecraft 1.20.1 には存在しないため対象から外しています。対象は1.20.1 に存在する原木のみです。
2. **ツツジ（アザレア）**：仕様どおり対象外にしています。
3. **連鎖の対象ブロック**：ツリーブレーカーと鉱石ブレーカーは、起点と同じブロック種のみを連鎖させます（原木は同じ種類の原木のみ）。
4. **家の判定**：ツリーブレーカーは、プレイヤー周囲の半径3に木材ブロックが8個以上ある場合に警告を出します（伐採は続行）。正確な建造物判定は行っていません。
5. **石系・砂系の範囲**：破壊面の向きに合わせて範囲を決めます。上下を向いている場合は上下方向に伸ばします。範囲破壊は連鎖ではなく、範囲外には広がりません。
6. **ストーンブレーカーのブロック単位の除外**：`player.stoneDisabledBlocks` にブロックIDを書くと対象外にできます（例：`"minecraft:granite"`）。GUIでの切替は Phase 8 で追加します。
7. **破壊速度30上昇（ガイドブックの記載）**：未確定のため実装していません。
8. **木の再植え付け**：苗木は `Blocks.*_LOG` の対応に従います。
9. **耐久の消費**：石系・砂系・鉱石は、追加で破壊したブロックごとに耐久を1消費します。ツリーは固定モード（既定）では1回のみ消費します。

## 既知の制限

- 連鎖処理は実行テスト（専用サーバーでの負荷・大規模な木や鉱脈）を行っていません。
- 木の再植え付けは、原木の下が土系の場合にのみ行います。
- 管理者設定の変更（GUI）、個別設定のGUIは Phase 8 で追加します。
- 作物関連（Phase 3）およびスポナーは未実装です。優先順位の枠だけ用意してあります。
